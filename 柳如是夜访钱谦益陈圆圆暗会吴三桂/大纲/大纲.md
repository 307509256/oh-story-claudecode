## 卷级大纲：全书三卷三十章

### 第一卷：初入秦淮·情窦初开（第1-10章，约10天剧情）
- 功能：铺垫双女主初入秦淮的起点+各自初恋定情+第一次交集
- 核心事件：柳如是女扮男装游金陵遇陈子龙；陈圆圆梨园成名遇冒辟疆；二女桃叶渡初遇结金兰
- 起始状态 → 结束状态：从秦淮八艳新人 → 各自找到初恋、名声初起；从互不相识 → 金兰姐妹

### 第二卷：乱世飘摇·红颜劫数（第11-20章，约48小时关键剧情+时间跨度3年）
- 功能：乱世转折+初恋破碎+政治婚姻+核心冲突爆发
- 核心事件：柳如是被陈子龙正妻逐出南楼→夜访钱谦益定情；陈圆圆被田畹掳走→转送吴三桂→李自成进京被刘宗敏掳→吴三桂冲冠一怒降清
- 起始状态 → 结束状态：从情窦初开 → 初恋破碎、被迫嫁给"对的人"；从太平盛世 → 国破家亡、山河变色

### 第三卷：尘埃落定·殊途同归（第21-30章，时间跨度20年）
- 功能：各自归宿+关系修复+闺蜜互助+最终结局
- 核心事件：钱谦益降清水太冷事件+李香君血溅桃花扇+董小宛入宫之谜+柳如是资助抗清+陈圆圆劝阻吴三桂未果出家+柳如是自缢+二女最后一面
- 起始状态 → 结束状态：从国破家亡 → 各自找到内心归宿；从政治夫妻 → 相濡以沫（柳钱）/貌合神离（吴陈）；从金兰姐妹 → 天人永隔
