# 衡阳会战背景设定

## 时代背景
- 时间：1944年（民国三十三年）夏
- 大背景：日军"一号作战计划"（豫湘桂战役），企图打通中国大陆交通线
- 长沙已于1944年6月18日陷落，日军铁蹄直指衡阳

## 衡阳战略地位
- 战时中国三大中心城市之一（与重庆、昆明并列），税收居全国第二
- 粤汉铁路与湘桂黔铁路交会点，西南门户、军事咽喉
- 人称"小南京""小上海"

## 衡阳会战关键时间节点
| 日期 | 事件 |
|------|------|
| 1944.6.23 | 日军10万兵力大举进攻，衡阳保卫战打响 |
| 1944.6.24 | 敌第六十八师团强渡湘江，从南面围攻 |
| 1944.6.26 | 衡阳机场被日军占领 |
| 1944.6.28 | 日军完成四面包围，发起第一次总攻 |
| 1944.7.11 | 日军第二次总攻，大量使用燃烧弹、毒气弹 |
| 1944.7.30 | 日军第三次总攻，四个半师团三面猛攻 |
| 1944.8.6 | 日军从北门攻入城内，展开巷战 |
| 1944.8.8 | 方先觉在得到"不屠城"承诺后率部投降，衡阳失守，坚守47天 |

## 参战双方
- 中方：国民革命军第十军，军长方先觉，兵力约1.7万人
- 日方：第十一军，司令官横山勇，兵力约10万余人
- 伤亡：日军伤亡约6万（含死亡约2万），中方伤亡约1.5万（牺牲约6000-7000，城破时伤患7000余）

## 城内环境（故事发生地）
- 衡阳城：湘江环绕，丘陵地形，街道纵横
- 主要地标：
  - 中央银行衡阳分行（地下金库，可作避难所）
  - 回雁峰（城南制高点）
  - 莲湖台（核心阵地之一）
  - 衡阳天主教堂（城破后战俘关押地）
  - 衡阳火车站/机场（6.26失守）
  - 林家公馆（城西西正街，林若男家）
  - 第十军军部（中央银行地下金库）
- 城内情况：战前居民大多疏散，留下的多为贫民、老弱或不愿离乡者；粮弹补给靠空投，后期严重不足；盛夏酷暑，痢疾流行

## 参考史料
- 方先觉"最后一电"："敌人今晨由城北突入以后，即在城内展开巷战，我官兵伤亡殆尽，刻再无兵可资堵击。职等誓以一死报党国，勉尽军人天职，决不负钧座平生作育之至意，此电恐为最后一电，来生再见。"
- 日军承诺"不屠城"后方先觉投降，战后余波在史学界有争议
