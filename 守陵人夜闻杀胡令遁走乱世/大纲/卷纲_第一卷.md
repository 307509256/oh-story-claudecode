# 第一卷 北邙惊变 卷纲

## 基本信息
- 卷名：北邙惊变
- 字数：约10万字
- 章数：30章
- 时间跨度：东晋永和六年（后赵青龙元年，公元350年）闰二月-六月
- 地理跨度：北邙山西晋皇陵 → 洛阳城 → 缑氏 → 阳城（嵩山） → 许昌 → 颍川 → 汝南 → 寿春

## 核心情绪
紧张感 + 乱世残酷感 + 小人物的挣扎感。开篇先给点轻松的日常（两个守陵人喝酒扯淡），然后杀胡令传来，节奏瞬间拉紧，一路逃亡，每章都有生死危机，中间穿插一点温情（三人关系变化）和震撼（历史人物的侧面展现），结尾到达寿春，暂时松一口气，但留下更大的悬念（沈劲招募壮士北伐，石衍动心，东晋真的是天堂吗？）

## 爽点节奏
- 第1-3章：开篇钩子（杀胡令夜），紧张感拉满，救人冲突
- 第4-6章：第一次遭遇乱兵，石衍杀人，第一次直面死亡，刘循克服恐惧
- 第7-10章：洛阳城惨状，对冉闵幻想破灭，逃出洛阳
- 第11-15章：坞堡风波，遇到第一个坞堡主，胡人汉人都在受苦，刘殊第一次对石衍改观
- 第16-20章：流民队伍，加入流民群，遇到饥荒，人相食的震撼，三人关系拉近
- 第21-25章：许昌之战，冉魏军和后赵残余军队打仗，被卷进去，石衍第一次展现军事才能救了大家
- 第26-30章：淮河边上，遇到东晋军队，被当奸细抓起来，遇到沈劲，化解危机，渡过淮河到达寿春，卷末沈劲邀请石衍一起北伐，留下悬念

## 人物弧线
- **刘循**：从"事不关己高高挂起"的混子，到被迫救人，再到主动保护孩子，中间几次想扔下孩子自己跑，最后还是狠不下心，终于明白有些事比自己的命重要。
- **石衍**：从"胡汉和我没关系，谁给饭吃跟谁"的老兵油子，到因为自己的胡人身份被追杀，看到冉闵军队滥杀无辜，也看到汉人百姓被乱兵杀，开始思考"我到底是谁"，保护刘殊不再只是因为兄弟义气，也因为他不想让孩子再经历自己小时候的事。
- **刘殊**：从一开始恨所有汉人、不信任任何人，到看到刘循和石衍拼命保护他，看到汉人也救胡人、胡人也救汉人，仇恨开始动摇，第一次开口叫"石叔"。

## 伏笔埋设
1. 刘殊腰带上的羊脂玉扣，不只是刘曜的遗物，里面藏着刘曜当年留下的密信（关于前赵埋在某地的宝藏？不对，不搞金手指，密信其实是刘曜写给儿子的遗言，让他不要报仇，要好好活着，做个好人——这是后期刘殊放下仇恨的关键）
2. 石衍胳膊上的刺青，是石勒当年给亲卫刺的，后来这个刺青被冉魏军队认出来，差点惹来杀身之祸
3. 刘循算卦的本事，不是全骗人的，他真的懂点天象，后来在战场上帮过忙
4. 他们在北邙山皇陵里拿的一点碎银子，救了他们好几次命，但也引来过劫匪
5. 佛图澄当年给石衍的一串佛珠，石衍一直带在身上，后来救过他一命（挡住了一箭）
6. 路上遇到的一个瞎眼老琴师，弹得一手好胡笳，是刘琨当年的旧部，给他们讲了刘琨吹笳退敌的故事，后来老琴师死了，把胡笳留给了刘循
